Cómo funciona esta versión

  • Macro: usa el histórico público del Radar para las series FRED disponibles.
  • Corporativo: consulta SEC EDGAR desde el servidor para datos XBRL y presentaciones oficiales.
  • Cripto: BTC consulta la API pública documentada de Binance Spot; el precio corresponde a ese mercado y a una ventana móvil de 24 horas.
  • Acciones y ETF: no se muestra cotización cuando no existe una licencia de datos autorizada para esta aplicación privada.
